# Daily Water Intake

A small, free application that involves tracking your daily water intake because I refuse to pay for one.

Full feature list, name and 1.0 coming soon!

Roadmap:
  Reach 1.0- This version will include water totals for the day, weeks, months and year. The final version will include the ability to add other liquids, so users can get a better understanding of how it compares to their water intake. In addition, users will be able to quickly add if the exercised, or the temperature of the weather which will alter the users total water intake for the day. Lastly, this app will run as a standalone application which will be able to install on handhelds and receive notifications. And of course, other quality improvements! Once the app reaches 1.0, it will begin its process porting over to the iOS store.
